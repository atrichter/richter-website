# original_files

Archival design and image source files — not part of the running site, uploaded for safekeeping and reference.

## Contents

- **`design/`** — Design project files (mostly Adobe InDesign/Illustrator), organized by project.
- **`graphics/`** — Standalone graphics and logo assets.
- **`pictures/`** — Personal photos used on the site, in multiple crops/formats, plus raw camera files.
- **`resume/`** — Resume source files and an alternate version.
- **`arHome.png` / `arHome-socialPreview.png`** — Homepage image and social preview image.
